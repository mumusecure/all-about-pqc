# All About PQC — 제작 계획서

> 작성일: 2026-11-03 · 상태: 확정 (v3)

## 1. 목표

- **독자**: 컴퓨터공학·수학 학부생. 암호·양자 배경지식은 거의 없지만, 대학원 수준의 깊이를 원함.
- **도달 수준**: 격자 기반 PQC 연구실(특히 격자 이론·암호해석 중심)에서 논문을 읽고, 실험을 돌리고, 첫 연구 질문을 던질 수 있는 수준.
- **무게중심**: 격자 축소·암호해석 ≫ 대수적 격자(이데알·모듈 격자) > 격자 암호 설계(LWE·NTRU 계열) > 주변 주제(영지식 증명, 동형암호, 동종사상). 구현은 연구 실험 도구로서 다룬다.

## 2. 커리큘럼 (8부 26장)

표기: ◆ 격자 이론·암호해석 핵심 · ★ 핵심 경로

모든 장은 세 층으로 구성한다: **직관**(비유·위젯) → **정식화**(정의·정리·증명 스케치·작은 수 예제) → **연구 관점**(핵심 논문 2–3편과 읽는 순서, 열린 문제). 연습문제는 ★/★★/★★★(대학원 과제 수준) + 해설.

### 0부. 오리엔테이션
- 0장★ 왜 PQC인가 — Harvest-now-decrypt-later, Mosca 부등식, 연구 지도, 실습 환경(Python·SageMath·fplll)

### 1부. 기초
- 1장★ 암호학을 정의로 — 게임 기반 안전성, 환원 증명, ROM/QROM 기초
- 2장★ 수학 I — 군·환·체, 이데알과 몫환, CRT, 유한체, 다항식 환
- 3장 공개키 암호의 구조 — KEM/DEM, 서명, FO 변환 미리보기
- 4장 식별 프로토콜과 Fiat-Shamir, 영지식 입문
- 5장 양자 위협 — 쇼어·그로버, 숨은 부분군 문제와 격자

### 2부. 격자의 기하와 알고리즘 ◆
- 6장★ 수학 II — 선형대수, 확률, 이산 가우시안
- 7장★ 격자 기초 — 기저, 행렬식, 쌍대, 연속 최소값, Minkowski, Gram-Schmidt
- 8장★ 격자 문제와 난이도 — SVP/CVP/BDD/uSVP, 근사 인자, 환원
- 9장★ LLL 완전 정복 — 알고리즘, 정확성·복잡도 증명, 직접 구현
- 10장 BKZ·열거·sieving — GSA, 비용 모델, fplll 실습

### 3부. 대수적 격자 ◆
- 11장 대수적 정수론 입문 — 수체, 정수환, 이데알, 원분체, canonical embedding
- 12장 이데알/모듈 격자 — Ring-LWE, Module-LWE, Ring-SIS
- 13장 모듈 격자 축소 — module-LLL, 부분체 기법

### 4부. 격자 암호 설계
- 14장★ LWE — Regev 암호, 최악→평균 환원, LWR
- 15장★ NTRU — 구조, NTRU 문제, 사례: NTRU+
- 16장★ ML-KEM 해부 — NTT, FO 변환, 복호 실패, 사례: SMAUG-T
- 17장 격자 서명 — ML-DSA, HAETAE, FN-DSA(GPV), HAWK(LIP)

### 5부. 격자 암호해석 ◆
- 18장 LWE 공격 — primal(uSVP)·dual·hybrid, core-SVP, lattice estimator
- 19장 NTRU 공격 — overstretched NTRU, 부분체 공격, dense sublattice
- 20장 복호 실패 공격과 구현 공격 개관 — KyberSlash, 부채널

### 6부. 주변 주제
- 21장 격자 기반 영지식 증명
- 22장 동형암호와 임계 FHE 입문
- 23장 동종사상과 SQIsign 입문
- 24장 다른 가문 개관 — 해시·코드·다변수·MPCitH, 표준화 현황(NIST·KpqC, 기준일 표기)

### 7부. 진로
- 25장 학부연구생·대학원 로드맵 — 연구실 찾기와 연락, 논문 읽기, 재현 프로젝트, 면접 대비

## 5. 품질 원칙

1. **수학 검증**: 모든 토이 구현(LLL, LWE, NTT, 토이 Kyber 등)은 단위 테스트로 검증.
2. **사실 확인**: 표준 현황·일정은 공식 문서(NIST, KpqC, IETF)로 확인하고 출처와 기준일 표기.
3. **화면 검수**: 모바일·데스크톱 스크린샷 확인, 라이트/다크 테마.
4. **장 템플릿 준수**: 학습 목표 → 선수 지식 체크 → 직관 → 정식화 → 연구 관점 → 연습문제 → 요약·참고문헌.
