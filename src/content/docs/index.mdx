## 이 교과서의 특징

<CardGrid>
  <Card title="세 층으로 읽는다" icon="open-book">

  </Card>
  <Card title="손으로 만지는 수학" icon="puzzle">

  </Card>
  <Card title="격자 중심, 연구 지향" icon="star">

  </Card>
  <Card title="진로까지 연결" icon="rocket">

  </Card>
</CardGrid>
