## 과제

**과제 1. 코드 읽기.** `lll()` 함수에서 (a) 크기 축소, (b) Lovász 조건 검사, (c) 교환 후 GSO 갱신에 해당하는 줄을 찾아 9장의 의사코드·연습문제 3 의 공식과 하나씩 대응시키세요.

**과제 2. 실패 경계 측정.**

```bash
python3 lab01_lll_lwe_attack.py --sweep --q 97 --sigma 1 --n-min 8 --n-max 44 --n-step 4 --trials 10
python3 lab01_lll_lwe_attack.py --sweep --q 97 --sigma 2 --n-min 8 --n-max 36 --n-step 4 --trials 10
```

각 설정에서 성공률이 50% 가 되는 $n$ 을 찾고 표로 정리하세요. 큰 $n$ 은 몇 분씩 걸릴 수 있습니다(순수 Python 이므로).

**과제 3. 가설 세우기.** 경계 지점의 격자 차원 $d$ 와 gap 을 그래프로 그리세요. "LLL 은 gap 이 대략 $c \cdot \delta^d$ 보다 크면 성공한다"는 꼴의 가설을 세우고 $c, \delta$ 를 추정해 보세요. 9장에서 본 $\delta_0 \approx 1.02$ 와 비교하면 어떤가요?

**과제 4. 확장 (택 1).**

- (a) `m` 을 $2n$ 이 아닌 다른 값으로 바꿔 보세요. 샘플을 *덜* 쓰는 것이 오히려 공격에 유리한 구간이 있나요? (힌트: 18장에서 다룰 "최적 샘플 수")
- (b) 비밀을 이진 $\{0, 1\}$ 이나 삼진 $\{-1, 0, 1\}$ 로 바꾸고 결과를 비교하세요.
- (c) `--fpylll` 로 같은 표를 만들어 속도와 성공률을 비교하세요.

<Aside type="tip" title="포트폴리오로 만들기">
결과를 **1쪽 보고서**(실험 설정 → 표·그래프 → 관찰 → 가설 → 한계)로 정리해 저장소나 블로그에 올리세요. "논문의 주장을 작은 규모로 재현하고, 숫자로 말하고, 한계를 적는" 능력은 연구실이 학부연구생에게 가장 먼저 기대하는 것입니다.
</Aside>
