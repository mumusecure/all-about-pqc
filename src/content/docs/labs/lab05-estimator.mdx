## 과제

**과제 1. 코드와 수식 대응.** `primal`, `dual`, `drop_hybrid` 의 각 줄을 18장의 휴리스틱 18.1, 3절의 식, 4절의 $p$ 와 대응시키세요. 특히 비밀 재조정 `nu` 와 `c` 가 왜 서로 역수 관계인지 설명하세요.

**과제 2. 민감도 표.** ML-KEM-768 을 기준으로 다음을 하나씩 바꾸고 core-SVP 가 몇 비트 움직이는지 표로 만드세요.

| 바꾼 것 | primal β | 비트 변화 |
|---|---|---|
| 기본 | 623 | 0 |
| 표본 수 상한 $m \le 2n$ | | |
| $\sigma$ 를 10% 키움 | | |
| $\log_2 q$ 를 1 늘림 | | |
| $\delta_\beta$ 에서 $(\pi\beta)^{1/\beta}$ 항을 뺌 | | |

마지막 줄은 "공식의 작은 근사가 결과를 얼마나 움직이는가(또는 움직이지 않는가)"를 보는 실험입니다. 명령행 옵션이 없으니 `delta_beta` 함수를 직접 고치세요. 표본 수 상한은 `--m`, 나머지는 `--n 768 --logq 11.70 --sigma ...` 로 바꿉니다.

<details>
<summary>검산용 값</summary>

이 스크립트로 계산한 primal β 와 core-SVP 변화: 기본 623 (0), $m \le 2n$ 623 (0, 최적 $m = 688$ 이 이미 $n$ 보다 작아 상한이 의미 없음), $\sigma$ 10% 증가 640 (+5.0 비트), $\log_2 q$ +1 570 (−15.5 비트), $(\pi\beta)^{1/\beta}$ 항 제거 623 (0). 마지막 항은 $\beta \approx 600$ 에서 $\delta_\beta$ 를 $10^{-5}$ 수준으로만 바꿔 β 가 그대로입니다. 공식의 근사보다 $q$ 와 $\sigma$ 같은 파라미터가 훨씬 크게 움직인다는 것이 결론입니다.

</details>

**과제 3. 다른 스킴.** FrodoKEM-640 형태($n = 640$, $q = 2^{15}$, $\sigma \approx 2.8$)와 15장의 NTRU 파라미터(NTRU 를 LWE 처럼 보면?)에 돌려 보세요. NTRU 를 LWE 모델로 추정하는 것의 문제점은 [19장](../../ch19-ntru-attacks/)의 주제입니다.

**과제 4. lattice estimator 와의 차이.** `--compare` 로 Kyber 세 집합의 primal·dual 을 돌리고, 자체 추정기와의 차이를 (a) 분포 모델, (b) 표본 수, (c) 비용 모델, (d) 공격 변형으로 나눠 설명하세요.

<Aside type="tip" title="포트폴리오로 만들기">
"공식 추정치를 직접 재현했고, 각 가정이 몇 비트를 움직이는지 정량화했다"는 1쪽 보고서는 파라미터 분석을 하는 연구실에 바로 보여 줄 수 있는 결과물입니다. 과제 2 의 표가 핵심입니다.
</Aside>
