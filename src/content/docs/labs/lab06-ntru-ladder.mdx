## 과제

**과제 1. 코드 읽기.** `ntru_lattice` 의 기저가 왜 $\{(u, v) : u \equiv vh\}$ 를 생성하는지, `rotations` 가 왜 $\pm$ 와 $n$ 개 회전을 모두 담는지 설명하세요. `inv_mod` 가 $f$ 의 곱셈 행렬로 연립방정식을 푸는 방식도 확인하세요.

**과제 2. q 에 따른 β.**

```bash
python3 lab06_ntru_ladder.py --n 32 --qs 11,13,17,23,29,37 --seeds 3
```

$\log_2 q$ 에 대해 필요한 $\beta$ 를 그리고, 회전이 1 개만 나오는 경우와 거의 $n$ 개가 나오는 경우를 구분해 표시하세요. 두 영역의 경계는 어디인가요?

**과제 3. n 에 따른 경계.** $n = 24, 28, 32, 36$ 에서 "LLL 만으로 풀리는 가장 작은 $q$"를 찾고(키 3 개 이상), $\log q$ 를 $\log n$ 에 대해 그려 기울기를 구하세요. 19장 연습 8 의 질문(왜 2.484 가 그대로 나오지 않는가)에 답하세요.

**과제 4. 확장 (택 1).**

- (a) 비밀을 삼진 대신 $\{-2, \dots, 2\}$ 균등으로 바꾸고 같은 표를 만드세요. 경계가 어느 쪽으로 움직이나요? (19장 3.2절의 주의 상자)
- (b) 19장 4절의 노름 사상을 구현해, 큰 $q$ 에서 지수 2 부분체의 격자($n/2$ 차원 NTRU)를 LLL 로 풀고 원래 격자와 시간을 비교하세요.
- (c) fpylll 이 있으면 `bkz` 를 fpylll 의 `BKZ.reduction` 으로 바꿔 $n = 64$ 이상으로 확장하세요.

<Aside type="tip" title="포트폴리오로 만들기">
"$q$ 와 $n$ 에 따른 필요한 β 표 + 회전 개수로 본 DSD 의 징후 + 큰 규모 결과(DvW21)와의 비교"는 overstretched NTRU 라는 연구 주제를 직접 만져 본 증거가 됩니다. 논문 읽기 1(MiNTRU)과 함께 정리하면 더 좋습니다.
</Aside>
