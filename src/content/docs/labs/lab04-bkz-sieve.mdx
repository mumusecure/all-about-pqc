## 과제

**과제 1. 코드 읽기.** `enum_block` 에서 (a) 부분합 $\ell_i$ 를 갱신하는 줄, (b) 지그재그 순서를 만드는 `advance`, (c) "위가 모두 0 이면 한 방향만" 처리하는 이유를 10장 3.1절·연습 8 과 대응시키세요. `insert_vector` 가 왜 격자를 바꾸지 않는지도 설명하세요.

**과제 2. β 와 δ.** 다음을 실행해 표를 만드세요.

```bash
python3 lab04_bkz_sieve.py --bkz --d 50 --betas 2,6,10,14,18,22 --seeds 3
```

(a) 측정 $\delta$ 를 β 에 대해 그리고, Gama–Nguyen 의 참고값과 비교하세요. (b) 노드 수의 $\log_2$ 를 β 에 대해 그려 기울기를 구하세요. 체의 $0.292$ 와 비교하면 어떤가요? (힌트: 작은 β 에서 열거는 체보다 쌉니다. 10장 EnumCost 위젯.)

**과제 3. 체의 기울기.**

```bash
python3 lab04_bkz_sieve.py --sieve --nmin 16 --nmax 32
```

출력의 기울기를 $0.2075$ 와 비교하고, 찾은 벡터의 길이가 Gaussian heuristic 에 얼마나 가까운지 보세요. 충돌 기준(300)을 바꾸면 무엇이 달라지나요?

**과제 4. 확장 (택 1).**

- (a) `enum_block` 에 **선형 가지치기**(레벨 $k$ 에서 반지름 $R_k^2 = \tfrac{k}{d}R^2$)를 넣고, 노드 수와 성공률(최단 벡터를 찾는 비율)을 비교하세요.
- (b) BKZ 를 **진행형**(β = 4, 6, 8, … 로 조금씩 키우며 한 바퀴씩)으로 바꾸고, 같은 최종 β 에서 총 시간이 줄어드는지 보세요.
- (c) `--fpylll` 로 $d = 80$, $\beta$ 를 30~50 까지 늘려 $\delta$ 가 공식 $\delta_\beta$ 에 가까워지는 β 를 찾으세요.

<Aside type="tip" title="포트폴리오로 만들기">
"β 에 따른 δ·시간 표, 체 목록 크기의 기울기, 그리고 공식과 어긋나는 구간과 그 이유"를 1쪽으로 정리하세요. 격자 암호해석 연구실은 비용 모델을 실험으로 보정하는 일을 많이 합니다. 이 보고서가 그 일의 축소판입니다.
</Aside>
